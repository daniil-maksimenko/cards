# Wortapotheke

Карточки и упражнения для лексического минимума по немецкому языку:
фармацевтический факультет, 1 курс, 1 семестр. Четыре темы, 225 слов и выражений.

Сайт — это один файл `index.html`. В нём слова, оформление, шрифты и вся логика,
поэтому он работает и на GitHub Pages, и просто с диска, и без интернета.

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `index.html` | Весь сайт. Достаточно его одного. |
| `sw.js`, `manifest.webmanifest`, `icons/` | Чтобы сайт открывался без сети и ставился на телефон как приложение. |
| `.nojekyll` | Пустой файл-подсказка для GitHub Pages. Если потеряется при загрузке — ничего страшного. |
| `LICENSE-FONTS.txt` | Лицензия встроенных шрифтов. |

## Как выложить на GitHub Pages

1. Зайди на [github.com](https://github.com), нажми **+** → **New repository**.
   Имя — например `wortapotheke`, видимость **Public**. Нажми **Create repository**.
2. На странице нового репозитория нажми **uploading an existing file**
   (в уже непустом репозитории: **Add file → Upload files**).
   Перетащи туда **содержимое** этой папки — файлы и папку `icons`, а не саму папку.
   Нажми **Commit changes**.
3. Открой **Settings → Pages**. В блоке **Build and deployment** выбери
   **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.
4. Через минуту-две на этой же странице появится адрес сайта:
   `https://ТВОЁ-ИМЯ.github.io/wortapotheke/`

`index.html` должен лежать в корне репозитория, рядом с папкой `icons`.

## Режимы

**Карточки.** Нажми на карточку или пробел, чтобы перевернуть. Потом «Знаю» или «Не знаю»:
кнопками, свайпом вправо/влево или стрелками → и ←. Backspace отменяет последний ответ.

- *Случайные* — слова наугад из отмеченных тем.
- *Новые слова* — те, что ещё не встречались, по порядку списка.
- *Трудные слова* — те, в которых была ошибка.
- *По порядку* — все слова отмеченных тем, как в списке.

**Упражнения.**

- *Тест* — четыре варианта, один верный (клавиши 1–4).
- *Письмо* — видишь перевод, пишешь по-немецки. Засчитывается ответ без заглавных букв,
  с `ae / oe / ue / ss` вместо `ä / ö / ü / ß` и без артикля — но сайт покажет, как правильно.
- *Артикли* — der, die или das (клавиши 1–3). Ответы здесь не меняют ярлык слова.
- *Пары* — соединить слова с переводами на время.

**Ярлыки слов.** Ошибка отправляет слово в «Трудные». Один верный ответ после ошибки —
слово становится «Учу», второй подряд — «Знаю».

**Настройки** (значок справа вверху): что показывать на лицевой стороне карточки,
сколько слов в одном подходе, озвучка, сохранение прогресса в файл.
Озвучка берёт немецкий голос самого устройства; если такого голоса нет, слово может прозвучать неверно или не прозвучать вовсе.

## Где хранится прогресс

Только в браузере на этом устройстве. Чтобы перенести его на другое устройство:
**Настройки → Сохранить в файл**, а там — **Загрузить из файла**.
В режиме инкогнито прогресс пропадает, когда закрываешь окно.

## Как поменять слова

Открой `index.html` на GitHub, нажми карандаш (**Edit this file**). Слова стоят в самом начале файла.
Одна строка — одна карточка:

```js
[5, "die Neigung", "Pl. Neigungen", "склонность"],
```

По порядку: номер в списке, немецкое слово, грамматическая помета (можно пустую `""`), перевод.

- Существительное пиши с артиклем `der / die / das` — тогда оно попадёт в «Артикли».
- Пятым элементом можно разрешить другие написания для «Письма»:
  `[58, "selbständig", "", "самостоятельный", ["selbstständig"]]`.
- Не теряй запятые в конце строк и кавычки вокруг слов.
- Прогресс привязан к немецкому слову. Изменишь его написание — для сайта это новое слово.

Сохрани изменения кнопкой **Commit changes**. Сайт обновится через минуту-две.

## Что изменено по сравнению с исходным списком

Опечатки:

- `Stomotologie` → `Stomatologie`, `Lerhstuhl` → `Lehrstuhl`;
- `abschlieβen` (с греческой β) → `abschließen`; `genoß` → `genoss` (по действующей орфографии).

Содержание:

- **den Unterricht erteilen** — в списке стоит перевод «преподаватель»; на сайте «преподавать, вести занятия».
  Если на занятиях требуют вариант из списка, поправь эту строку.
- **leiten; der Leiter** — в списке один перевод «руководить». На сайте две карточки:
  `leiten` — руководить, `der Leiter` — руководитель.
- `Aufnahmeprüfung` получила артикль `die`; `die Aula-, en` записана как `die Aula`, Pl. Aulen.

Запись:

- `f / m / n / s / pl` заменены на артикли `die / der / das`; знак `~` раскрыт
  (`~ für Anatomie` → `der Lehrstuhl für Anatomie`).
- Возвратные глаголы начинаются с `sich`: `sich beschäftigen`, `sich interessieren`.
- Формы множественного числа и основные формы глаголов выписаны целиком:
  `-¨e` → `Pl. Zusätze`, `(a, o)` → `empfahl, empfohlen`.
- Сокращения в переводах раскрыты: «ф-т» → «факультет», «гос.» → «государственный», «pl.» → «мн. ч.».
- Если под одним номером стояло несколько слов, каждое стало отдельной карточкой с тем же номером:
  `der Beruf` и `von Beruf sein`, `verheiratet sein` и `ledig sein`, `die Bücherei` и `die Bibliothek`,
  выражения с `Arznei`, `Medikament`, `Kosten`.

Семь слов стоят в двух темах сразу (`der Beruf`, `das Fach`, `die Fakultät`, `die Fakultät für Stomatologie`,
`der Lehrstuhl`, `sich beschäftigen`, `abschließen`). В словаре они показаны в обеих темах, прогресс у них общий.
Поэтому строк в словаре 232, а разных слов 225.

## Исходники

Если хочется менять оформление или логику, удобнее работать с исходниками (папка `wortapotheke-src`):
`words.js`, `styles.css`, `app.js`, `template.html`. Команда `python3 make.py` собирает из них `index.html`.
Сборка перезаписывает `index.html`, поэтому слова в этом случае меняй в `words.js`.
